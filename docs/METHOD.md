# 多年方法

核心：2023-07至2026-06三年平均年度份额40%、同发表年引用背景20%、三年去重机构15%、活跃季度比例15%、最近一年份额10%。要求三年≥750篇，每年≥150篇，12季度至少9个季度各≥25篇，最近一年≥250篇且同比份额比≥0.8。

新兴：最近2025-07至2026-06，与此前2022-07至2025-06三个完整非重叠年度的份额均值比较；历史轨迹为2021-07至2026-06。长期比值权重35%、最近同比25%、三年对数份额斜率20%、增长季度10%、机构扩展10%。门槛及跨过滤确认见快照data/MULTIYEAR_METHOD.json。年度分别归一，避免收录量大的一年独占背景。

新兴不等于新技术起源；成熟技术也可能持续升温。低基数方向、历史峰值以下的恢复及未审数值候选保留观察。多年数据增加稳定性，但不自动消除语义混杂、日期代理、学科构成或收录变化。

机构按规范化名称计数，跨年取并集，不能把各年机构数直接相加。新兴机构背景使用每年度机构数的均值，不拿三年机构并集与最近一年比较。引用为快照累计引用同年百分位；历史截止点使用当前标签和引用快照，不能称为前瞻预测回测。

当前26个方向新增192条跨年样本阅读，属于Codex辅助初审，非独立专家金标准；个别已保留方向仍有明确误分，报告逐项说明。全部750类计算，202个核心与44个新兴数值候选并不等于全部语义通过。

潜在仍为四个任务单元：同一专利集合提供规模和申请主体，论文同任务定义，政策同任务复核；二元平滑分母+1；双方1至5月同期比较。基线3项中2项双口径支持、1项条件跟踪；知识图谱观察。没有凭论文历史构造专利多年趋势。
