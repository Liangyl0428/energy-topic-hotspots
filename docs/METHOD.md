# 热点智能分析方法

读取全部5,119,004条分类记录，按论文日期、可用文本、撤稿和模板标记筛选，以2026-06-30为截止日构建2021Q3—2026Q2完整主题×季度网格。缺测不能冒充零。

## 评分

季度论文份额采用0.5平滑：(主题篇数+0.5)/(季度总篇数+0.5×主题数)。机构名称去重，引用按发表年份队列计算百分位；近期为一年，核心默认三年，新兴背景为前三年。

核心分数=100×(0.40×规模百分位+0.20×引用百分位+0.15×机构百分位+0.15×持续性+0.10×近期份额百分位)。

新兴分数=100×(0.35×多年份额增长百分位+0.25×近期增长百分位+0.20×趋势百分位+0.10×季度增长一致性+0.10×机构扩张百分位)。

确切实现见[scoring.py](../src/energy_hotspots/scoring.py)。排序时按10位小数归并机器精度差异，并列按主题ID稳定排序，不改变原始分数。

## 数值门槛

核心：三年累计至少750篇，每年至少150篇；12季度至少9季度各25篇；近一年至少250篇；近期份额至少为前一年的80%。

新兴：近期至少100篇，背景年均至少50篇；多年份额比至少1.25、近期份额比至少1.15、至少3个季度增长；三年对数份额斜率大于0，相对背景峰值至少1.05；计数近似下界大于1.05，BH校正q值小于0.05。

当前287个核心、119个新兴数值候选仍需范围审核，候选集合可能重叠。

## 跨来源与边界

在共同2026年上半年窗口计算论文、专利、政策份额。潜在线索探索门槛为论文100、专利25、政策2、份额比1.25，并在实验中扰动。门槛未经人工标注校准，政策相似不等于同任务支持，专利快照不能证明多年增长。

模型使用全部年份，季度轨迹是回溯描述，不是独立预测验证。实验范围见[FULL_EXPERIMENTS.md](FULL_EXPERIMENTS.md)。
