# 热点如何识别

算法先计算指标、检查入选条件，再结合已记录的样本范围审阅形成专家初评候选。分数用于排序；较高的分数本身不能替代入选条件和主题范围判断。

实现位置：[scoring.py](../src/energy_hotspots/scoring.py)负责核心与新兴评分，[potential_unified_metrics.py](../pipelines/hotspots/potential_unified_metrics.py)负责潜在任务指标和门槛。完整调用关系见[算法代码导读](ALGORITHM.md)。

## 时间范围

| 用途 | 时间范围 | 为什么这样设置 |
| --- | --- | --- |
| 核心表现 | 2023年7月—2026年6月 | 观察三年的持续研究活动 |
| 最近状态 | 2025年7月—2026年6月 | 确认方向近期仍然活跃 |
| 新兴比较背景 | 2022年7月—2025年6月 | 将最近一年与此前三个不重叠年度比较 |
| 长期轨迹 | 2021年7月—2026年6月 | 识别持续抬升、历史峰值以下恢复等情况 |
| 潜在任务证据 | 2026年1—8月 | 汇总现有论文、专利及已核对的政策证据 |

“份额”是一个主题的论文数占同期背景论文库的比例。各年度先分别计算份额，再对背景年度取平均，避免收录量较大的年度主导比较。计算加入少量平滑量，防止零计数导致比值无法计算。

## 核心热点：研究规模与持续性

| 评分成分 | 权重 |
| --- | --- |
| 三年平均论文份额 | 40% |
| 同发表年份的引用表现 | 20% |
| 三年去重研究机构数 | 15% |
| 活跃季度占比 | 15% |
| 最近一年论文份额 | 10% |

除活跃季度占比外，各成分使用候选范围内的百分位。加权评分按0—100分表示。

数值条件包括：三年论文不少于750篇；每年不少于150篇；12个季度中至少9个季度各有25篇；最近一年不少于250篇；最近一年论文份额不低于前一年的80%。还需满足能源电力范围要求，并通过对应的样本范围审阅。

## 新兴热点：多年背景上的持续升温

| 评分成分 | 权重 |
| --- | --- |
| 最近一年相对前三年平均份额的增长 | 35% |
| 最近一年相对前一年的份额增长 | 25% |
| 近三年对数份额趋势 | 20% |
| 同比增长的季度占比 | 10% |
| 研究机构参与广度的增长 | 10% |

数值条件包括：最近一年不少于100篇，前三年年均不少于50篇；最近一年份额至少为此前三年均值的1.25倍、前一年的1.15倍；至少3个季度同比增长；近三年趋势为正；最近一年份额超过此前四年最高值至少5%。

还要通过计数筛查和数据范围检查：合并背景年度的份额比95%近似下界大于1.05，BH校正后的q值小于0.05；文本日期质量、几何筛查、去重等范围中的增长方向，以及2026年1—8月同月份额比，均满足规定条件。完整参数见[方法参数文件](../assets/snapshot_20260925/hotspots/data/MULTIYEAR_METHOD.json)。

这些计数检验是筛查工具，未充分校正时间相关性与收录偏差。新兴描述关注度上升，成熟技术也可能入选。低基数信号、恢复性增长和语义待核查方向可在候选或观察表中查看。

## 潜在热点：具体应用任务的证据

“任务单元”指一个单独定义研究对象和应用任务的方向。这里分别评估虚拟电厂、空气源热泵、电力知识图谱与知识问答、电力大模型辅助决策与运维。一个主题可关联多个任务：例如C0356关联知识图谱和大模型两个任务。任务之间可能共享记录，因此不能直接相加得到互斥文献总数。

同一任务下，专利数和申请主体数由同一批专利记录计算；论文按相同任务定义筛选；政策逐项判断是否明确支持该任务。严格口径只纳入证据明确的记录，扩展口径加入范围待判断的记录。

入选条件为：专利不少于50组、已知申请主体不少于20个、明确部署或研发政策不少于2组；2026年1—8月和1—5月两个同期窗口的专利/论文相对份额均不低于1.25。

相对份额计算为：

```text
[(任务专利数 + 0.5) / (合格专利总数 + 1)]
÷ [(任务论文数 + 0.5) / (合格论文总数 + 1)]
```

例如，比值大于1意味着该任务在专利库中的相对占比高于在论文库中的占比；这本身不能证明技术领先。背景总数取自对应来源的合格记录库。

任务内排序使用专利数量百分位30%、申请主体数量百分位20%、政策强度50%。百分位仅在四个任务内计算，分数用于安排跟踪顺序。结果逐方向解释如下：

| 方向 | 仅明确相关记录（严格口径） | 加入待判断记录（扩展口径） | 结论 |
| --- | --- | --- | --- |
| 虚拟电厂 | 通过全部条件 | 通过全部条件 | 可跟踪；两种纳入范围均支持 |
| 电力大模型辅助决策与运维 | 通过全部条件 | 通过全部条件 | 可跟踪；两种纳入范围均支持 |
| 空气源热泵 | 通过全部条件 | 相对份额未达标 | 有条件跟踪；需核实待判断记录 |
| 电力知识图谱与知识问答 | 政策组数未达标 | 政策组数未达标 | 暂不推荐，保留观察 |

“双口径”说的是上述两种文献纳入范围。每次计算均使用同任务的论文、专利和政策证据；两次通过只说明结果对这种纳入范围变化较稳定。

空气源热泵的相对份额在1—8月窗口为1.85（严格）和1.19（扩展），在1—5月窗口为1.89和1.17。扩展范围的两个比值都低于1.25门槛，所以“条件性”具体指：需要先核实待判断文献是否属于该应用方向。知识图谱虽专利相对份额高，但只确认1组明确政策，未达到至少2组的要求。“观察”表示目前暂不推荐，并非断言该方向没有价值。

## 如何理解证据强度

全部750类均计算文献指标，202个核心、44个新兴数值候选与最终12个核心、22个新兴初评候选属于不同筛选阶段。样本范围审阅是模型辅助初审，不是独立专家金标准；跨年审阅记录包括26个方向的192条题名或摘录。主题通过审阅也不表示每条记录都分类正确。

研究机构按规范化名称跨年去重；新兴的机构背景使用各年度机构数的平均值。引用是数据快照中的累计引用，按发表年份比较，不是历史引用增长。专利申请主体按名称统计，尚未完成集团层面的归并。

更长窗口可以减少短期波动，但不能消除日期代理、文本缺失、检索漏检和分类边界问题。较早截止点的实验使用固定标签、样本判断与引用快照，属于回顾性敏感性分析。

## 排名与并列

排名时将0—100分舍入到小数点后10位，避免计算机浮点尾差影响并列关系。表格中的并列项按ID升序展示；实验名次采用并列最小名次，Spearman相关也使用舍入后的分数。原始计算分数保留，不以舍入后的分数判断入选门槛。
