# NMF500样本版下游重算

入口为 `pipelines/nmf500/build.py`，输出 `outputs/nmf500/`。本轮输入是
14.2万篇冻结论文样本，以及17,918条专利、5,865条政策的新主题关联结果。
不是原约512万条记录的全量重分类。主题号 `N0001` 至 `N0500` 对应
NMF组件0至499，不与旧 `C` 编号互换。

## 标签和时间

全部论文均用同一冻结NMF模型的 `transform` 推断。训练阶段保留的W与
固定H后的推断W可能不同；时间趋势不混用两种生成方式。
`uniform_inference_changes.csv`逐split记录变动。
统一标签后同步重建论文主题中心，验证集对训练中心重新校准置信阈值，
再重算专利/政策Top3。下游热点与成熟度案例关联使用同一更新中心；
`transfer_recalibration_audit.csv`记录相对于上游初版关联的变动。

核心窗口2023-07至2026-06，近期2025-07至2026-06，新兴背景
2022-07至2025-06，历史峰值检查2021-07至2025-06。只使用完整季度。
论文按期样本背景归一化，专利与政策各用自身观察样本分母；不外推全量。

## 核心和新兴

沿用原评分组件与权重。核心考察规模、引用、机构、持续性和近期活跃；
新兴考察多年份额增长、同比、趋势、季度一致性和机构扩张。
引用是当前快照中的累计引用，机构是样本中观察到的规范化名称。

样本数量门槛在查看排行前设置：核心三年平均至少60篇、每年至少30篇、
最近一年至少50篇、12季度至少9个季度各有5篇、同比份额不低于0.8。
新兴最近一年至少25篇、背景年均至少8篇；其余比值、置信下界和BH阈值
沿用原公式。降低样本支持门槛不代表转换为全量计数。

敏感性分别剔除无摘要论文、全局标题年度重复、1月1日代理日期。
核心稳健候选要求各过滤均通过数量门槛；新兴稳健候选要求主条件通过，
且各过滤的多年与同比份额比均不低于1.10。

数值候选与范围审阅分开。旧750主题的语义审阅结论不继承到新主题。
`candidate_evidence.csv`保留随机样本和高归属样本供核读；不以这些少量
样本估算主题纯度。

## 潜在热点

全500主题先计算跨来源候选信号。主筛选使用通过上游论文校准阈值的
专利/政策关联，同时提供全部关联作为敏感性对照。最近一年专利至少5条、
论文至少10篇、三年政策至少2条；专利相对论文份额比在最近一年和
2026年1—5月均至少1.25，后一个窗口至少2条专利。

该数值门槛只识别应用跟踪线索。余弦关联不证明政策明确支持同一任务；
当前样本缺少统一专利主体元数据。未完成同任务政策核读、主体多样性
验证的方向，不能宣称满足旧版的任务级潜在热点证据门槛。

## 复算

在原始数据工作区根目录：

```sh
.venv-hotspots/bin/python energy-topic-hotspots/pipelines/nmf500/build.py
.venv-hotspots/bin/python energy-topic-hotspots/pipelines/nmf500/review.py
.venv-hotspots/bin/python energy-topic-hotspots/pipelines/nmf500/validate.py
```

依赖numpy、pandas、scipy、scikit-learn、joblib、duckdb、pyarrow、
openpyxl、tabulate和threadpoolctl。额外输入包括原始论文元数据库
`analyze/data/independent_corpus.duckdb`。来源模型与稀疏矩阵、样本文件的
SHA256记录在 `PAPER_INPUTS.json`，输出目录被Git忽略。

## 本轮核读与结果

初筛8个核心、29个新兴和5个潜在数值候选。对40个不重复候选主题展示
代表论文并核读可用摘要、潜在候选的专利摘要和政策片段后，保留2个核心
条件性跟踪、8个新兴跟踪和3个潜在应用线索，其余暂缓认定。
人工可检查的判断保存在 `pipelines/nmf500/review_decisions.json`。
所有判断均为AI辅助初审，不是独立专家确认，也不是类内纯度估计。

核心2个为相变储热、强化学习用于能源调度；摘要/日期过滤下未全部通过
数量门槛，不能称为稳健核心。新兴8个为电力故障诊断、海上风电、能源
柔性、能效、能源材料电子结构、湍流与等离子体、建筑暖通、生命周期评价。
新兴只指样本份额上升，不意味着技术新颖性。

潜在线索为车网互动与充电、新型储能系统、电力网络安全。政策核读合并
同一计划的地方执行文件和重复转载，排除正文落款2006年的电网运行规则
作为近期政策；精确引文、URL、字符位置和哈希见 `policy_evidence_review.csv`。
潜在方向尚缺统一专利主体、全类同任务验证，因此没有宣称通过原版全部
证据门槛的潜在热点。

本轮统一推断改变1,735篇训练论文（1.55%）的标签；验证与回放标签不变。
同步更新中心后，646条专利、139条政策的Top1发生变化。
最终面向阅读的表为 `500主题热点审阅结果.xlsx`。
