# v0.2.1 严格审查与热点重算

结论：v0.2.0有可复现的统计基础，但主题歧义、证据范围与过滤敏感性不足以支持“自动可靠识别热点”。本版修复可执行缺陷并重新核读，未用更好看的名单替代质量验证。

## 修正

- 与主题仓库共享固定H、L2组件贡献推断。重算142,000篇论文，141,894篇进入统计（105篇无有效关键词，1篇Title Pending排除），并更新23,783条专利/政策关联。500个编号中499个活动；目录各来源与切分计数从新标签重新生成。
- 原评分入口只检查季度名称存在，单个主题缺季度会被补零；现要求每个主题×季度显式完整，缺机构或引用上下文、无穷值和错误热点类型也会报错。历史750 SQL稀疏聚合通过专用适配器展开已测零，历史回放结果保持可复现。
- 原“新兴稳健”只检查过滤后的增长方向，不要求仍过完整门槛。现核心和新兴都需通过全部五种过滤的完整门槛：有摘要、题名年度去重、非1月1日、贡献间隔≥0.05、每季度统一最多2,000篇。后两项是事后敏感性诊断，不是已校准的拒绝阈值。
- 通过论文相似度过滤不再清除专利/政策的语义复核标记；另有`similarity_filter_passed`用于数值筛选。
- 旧主题审阅不能跨版本沿用。新审阅绑定目录、样本、热点及潜在线索输入的SHA256；变动即拒绝沿用。政策条款另绑定具体文档、完整正文哈希和当前主题，核对实际发文日期，2006年旧规不作为近期支持。

潜在线索仍为储能系统、电力网络安全、充电与车网互动。主题总数/专利比值不代表这些窄任务的专属计数。

52个数值候选的题名初筛和保留方向可用摘要/政策片段审阅均为AI辅助，不是专家金标准。
发现钙钛矿主题混入显示和X射线检测；“Reduction”“Field”“Key”等多义或泛词构成混杂类；
需求响应主题的代表专利含交易需求匹配和储能需求分析，不能视为同任务支持。
`review_decisions_v021.json`保存52个候选的取舍理由及9条政策判定。无全量语义标注，不能报告准确率。

权重扰动、96个确定性情景和政策组留一从新结果重算，见`assets/nmf500/experiments/`。
相对v0.2.0生产结果，3,308条专利、1,061条政策的Top1改变；
`transfer_recalibration_audit.csv`是相对更早上游标签的对照，不能混作此处的版本增量。
排名稳定不代表入选准确、未来预测有效或证据独立；计数检验也未建模时间相关性和库外收录偏差。
原核心/新兴权重保留，未为保住名单调节门槛。没有主体多样性和全类同任务验证，充分验证潜在热点仍为0。
