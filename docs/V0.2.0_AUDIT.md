# v0.2.0：新旧逻辑对照与新500主题实验

## 一致性结论

不是全部照搬旧算法。以下对照相对于 `v0.1.0` 的750主题多年度版本。

| 项目 | 保持不变 | NMF500样本版的变化 |
|---|---|---|
| 核心评分 | 规模/引用/机构/持续性/近期权重 .40/.20/.15/.15/.10；3年窗口、同比份额 | 3年750→180篇；每年150→30；季度25→5；近期250→50；仍要求9/12活跃季度、同比≥0.8 |
| 新兴评分 | 多年增长/近期增长/趋势/季度一致/机构扩展 .35/.25/.20/.10/.10；独立年度份额、增长比、下界与BH筛选公式 | 近期100→25、背景年均50→8；样本过滤替代原全量质量/几何/去重和YTD稳健条件 |
| 引用口径 | 同出版年引用百分位；当前累计引用快照 | 旧DuckDB `percent_rank`；新pandas `rank(pct=True)`，并列及端点不同；不是完全一致的实现 |
| 范围审核 | 数值筛选后必须核读能源任务范围 | 新主题不继承旧750人工范围标签；40个数值候选主题仅作AI辅助样本核读，非纯度估计或专家认可 |
| 潜在热点 | 专利/论文同时间覆盖、独立来源分母、政策必须核读 | 原4个有界任务要求专利≥50、主体≥20、政策组≥2；新主题仅专利≥5、近期论文≥10、政策文档≥2等，且权重不同、缺主体多样性，因此仅称应用线索 |
| TRL/CRL | 原独立对象、逐门槛证据引擎与判据；未知留空 | 只更新主题候选关联和输出，主题不继承案例等级；详见成熟度仓库报告 |

原 `src/energy_hotspots/scoring.py` 默认门槛未改，旧750回放测试继续执行。
新参数只允许样本版调用者改变活动门槛；公式镜像文件与主模块保持一致。
新核心数量和稳健性均不足以支持“稳健核心”结论，目前是2个条件跟踪方向；
8个新兴是样本关注份额增长，不代表技术首次出现；3个潜在方向是应用线索。
不把样本支持阈值称为从全量门槛严格统计换算所得，也不外推全量规模。

## 关键实测结论

| 检验 | 核心 | 新兴 | 潜在线索 |
|---|---:|---:|---:|
| 权重扰动Spearman中位数 | 0.9996 | 0.9998 | 0.9834 |
| 权重扰动Spearman最小值 | 0.9967 | 0.9984 | 0.8401 |
| Top20重合率最小值 | 85% | 95% | 90% |

排名稳定不等于入选稳定：计数门槛提高20%，核心数值候选8→2，2个已核读
核心方向均未保留；新兴29→26，已核读方向8→7。去掉核心引用组件时Top20
重合率65%；去掉潜在线索论文组件时只有50%。

新兴背景窗口及年度留一保留6–7个原8个跟踪方向。取消迁移置信过滤时，潜在
数值候选5→11；余弦门槛提高0.02时5→3，原3个线索保留2个。
三个已核读潜在线索恰有2组政策，移除任意一组即不满足双政策组要求。
因此不能把它们升级为证据冗余充分的潜在热点。
