## 说明

1. 命中率高是正常的：词典本身就包含"电力系统 / 储能 / 电池 / 可再生能源 / 电极 / 氧化物"这类
   覆盖极大的词条，能源领域文档自然大量被它覆盖。覆盖率**不代表**这些文档都对某个具体技术方向有用——
   真正做热点判别时还要过 `config/hotspot_rules.json` 的背景词、跨域泛化、规模与增速门槛。
2. 若只看"非背景词"（排除近一年文档频率 ≥2.5% 的领域通用词）的命中量，会显著低于上表；
   该口径可按需另算。
3. 论文分母有两个：全库 4,831,088（跨 27 年）与本文分析窗 1,754,329（2021–2026）。
   引用"占总量百分比"时请说明用哪个分母。
