# 全量热点消融与灵敏度实验

入口为 pipelines/full_nmf/experiments.py，参数 --classification 指定全量分类目录，--input 指定全量热点输出，--output 指定实验输出。

由识别仓库的独立后续任务在基础全量结果完成之后执行，不停止或重启编码。直接核验全量分类清单、逐片哈希和完整记录数，不读取样本版计数或复用旧实验结果。

- 核心／新兴／跨来源关联各1500次±20%权重扰动，固定种子20260926，输出排名区间、Top20重合和秩变化。
- 逐评分成分、逐门槛消融；全量计数门槛联合±20%及单参数网格；全部候选仍待范围和语义核验。
- 核心1/3/5年窗口；新兴2/3/4年背景及背景年留一；引用年份固定为2023–2025，不能解释为独立历史回测。
- 全部论文的题名-only过滤、NMF贡献差距0.025/0.05/0.10过滤。每种过滤重算季度分母、机构集合和引用队列，禁止只改计数而保留不相容的上下文。
- 论文／专利／政策来源消融，专利政策余弦与间隔网格，2026H1/前5月/Q1共同日期窗口，政策文档留一。

跨来源潜在线索使用公开列出的探索性门槛（论文100、专利25、政策2、份额比1.25），并逐项扰动；它们未获人工标注校准，不是“已验证潜在热点”。新主题缺少政策族审核和申请人多样性资料，文档留一不能替代独立政策族留一。不得沿用旧主题人工结论。

大规模输入始终为全量；实验属于固定分类后的诊断，不重跑NMF，不给缺证据对象补等级。Spearman在恒定分数下留空。扰动区间不是统计置信区间。

输出包括 PROTOCOL.json、scenarios.csv、scenario_memberships.csv、weight_draws.csv、rank_intervals.csv、逐过滤季度及上下文、政策文档留一和报告。全部通过后复制到 assets/full_nmf500/experiments，再由识别仓库后续任务校验、提交和非强制推送既有origin/main。未出现最终推送回执时不能声称已发布。

本次发布还必须通过[主题效果对比](TOPIC_EVALUATION.md)的输入／输出校验；共同口径对比副本位于 assets/full_nmf500/topic_evaluation。不能只完成热点实验就跳过主题识别评测发布。
