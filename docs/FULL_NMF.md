# 全量NMF主题入口

`pipelines/full_nmf/build.py`消费主题仓库完成并核验的全量分类目录，输入须具有有效的`COMPLETE.json`和摘要校验和。拒绝样本版代替全量训练、全量推断或全量跨来源匹配。

```sh
.venv-hotspots/bin/python energy-topic-hotspots/pipelines/full_nmf/build.py
```

完整范围为5,119,004条冻结记录。热点统计按论文日期、撤稿及模板质量标记筛选，使用完整2021Q3—2026Q2季度；分类范围与热点时间窗口的记录数分别报告。核心门槛采用三年750篇、每年150篇、近期250篇、季度25篇；新兴近期100篇、背景年均50篇。权重沿用原评分模块。全量新主题仅生成数值候选，范围批准需要新审阅。

全部专利和政策匹配结果纳入来源统计，跨来源份额采用共同的2026年上半年窗口。政策余弦关联不能证明同任务支持，2026年专利快照不能证明多年专利增长。结果在`outputs/full_nmf500_20260926`，紧凑公开快照在全量流程完成后复制到`assets/full_nmf500`。
