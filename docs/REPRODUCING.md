# 复现边界

推荐使用README中的 `replay --experiments`。参考资产只读，复制必要输入至新目录后重新计算；21张文献结果表与潜在指标、10张实验表逐项对照。不是把参考输出直接复制成验证结论。

`data/multiyear` 包含6个范围下的季度与月度计数，以及主窗/历史截止点的机构和引用汇总。原始运行中这些量从文献重建；独立回放使用冻结汇总，不携带全量数据库。全库题名年度去重在上游执行，潜在只保留与候选相交的去重ID，但分母始终使用全库值。

`pipelines/hotspots/multiyear_prepare.py` 是原语料适配器，需要 `ENERGY_HOTSPOTS_UPSTREAM` 指向具有原布局的数据根目录，`ENERGY_HOTSPOTS_RUN` 指定工作目录。全量准备、抽样、最终打包和独立原始数据校验仍需要上游标签、元数据及审计备份，不属于精简包无外部数据入口。`common.py` 已移除本机私有依赖路径。

审阅决定、类别ID和潜在规则是本次冻结输入；应用于新数据必须重新评估语义，不能重用本轮通过名单。抽样程序只准备证据，执行程序不等于完成阅读。

快照data/VALIDATION.json为原完整交付核验；provenance/REPLAY_VALIDATION.json为独立仓库回放，两个范围不同。回顾性截止点实验使用当前标签、语义和引用快照，不是严格按历史可得信息重建的预测回测。

排序和实验排名统一采用小数点后10位的分数键，并列展示按ID升序。这样不同CPU/BLAS内核的浮点尾差不会改变候选顺序、并列名次或Spearman。回放仍严格对照行列顺序与字段，浮点值沿用原数值容差。
